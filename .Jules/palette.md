## 2026-08-08 - NcTextField Trailing Button Accessibility
**Learning:** In `@nextcloud/vue`, `NcTextField` provides a default localized label for trailing buttons based on `trailingButtonIcon` (e.g. `Clear text`), so explicit override is not strictly necessary unless customized wording is required.
**Action:** Verify built-in accessibility defaults in `@nextcloud/vue` components before overriding props.
