## What this repo does not carry

`CONTRIBUTING.md` and `SECURITY.md` are **to be** served organisation-wide from the public
[`APS-Conecta/.github`](https://github.com/APS-Conecta/.github) repository — the workflow, the
documentation rules, the ADR rules and how to report a vulnerability all live there, and a local copy
would exist only to contradict it. What cannot be inherited, and so stays here, is `CODEOWNERS`,
`.github/workflows/` and `.githooks/`.

> **Not live yet.** GitHub serves organisation defaults only from the default branch of
> `APS-Conecta/.github`, and both files are still on an unmerged branch there
> ([PR #1](https://github.com/APS-Conecta/.github/pull/1)). Until it merges this repository has
> no contributing or security document from any source. The docs gate reads the local clone, so
> it already counts them as present — that is deliberate, to keep the check offline, and it is
> why these close on **merge**, not on commit.

## A note on the ADR numbers

Sixteen ADRs, `0002`–`0017`, no gaps. **The numbering starts at 0002**: `0001` handed REM to a
sibling app that was later retired, and it was deleted rather than superseded (#121) — the number is
spent and nothing will be written at it. Numbers are never reused and never renumbered, so a gap
*between* two of these would be a permanent one rather than a deletion. Every ADR carries a dated
`Status:`; `0002`–`0008` were given theirs on 2026-08-08, dated from the commit that added each file,
because an ADR that cannot be superseded reads as live forever.

Decisions that reach past this app belong in the trunk repository, not here — see
[gestion ADR-0011](https://github.com/APS-Conecta/gestion/blob/main/docs/adr/0011-org-wide-facts-live-in-gestion.md).
[ADR-0003](adr/0003-establishment-is-instance-configuration.md) was that case — it bound *"every app
here"* from one leaf repo — and moved to the trunk on 2026-08-09 as
[gestion ADR-0013](https://github.com/APS-Conecta/gestion/blob/main/docs/adr/0013-the-establishment-is-instance-configuration.md).
The number keeps a stub and is never reused.
