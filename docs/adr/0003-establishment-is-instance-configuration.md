# The establishment is instance configuration, never a constant

Every app on this platform must be **CESFAM-agnostic**: no DEIS code, clinic name or comuna appears
in code, fixtures or queries. The establishment is supplied at install and read from configuration.
`gestion` already works this way — `sites/<slug>/site.sh` carries the whole clinic identity
(`SITE_DEIS`, `SITE_NOMBRE_CORTO`, `SITE_COMUNA`, `SITE_SERVICIO_SALUD`), is generated by
`scripts/deis.py <deis>` and sourced by `seed.sh` before the phase loop. What was missing is that
nothing propagated it into the apps; a provisioning phase now pushes it to an app config key that
both `analizador_rem` and Epidemiología read.

**One establishment per instance.** Another clinic is another `sites/<slug>/site.sh` and another
deployment — the shape #77 and #110 already build toward — not another entry in a picker.

## Considered options

- **A run-time selector over the national extract.** DEIS publishes every establishment in one file,
  so this is nearly free on the data side. Rejected for now on two grounds: it reverses
  `analizador_rem`'s explicit non-goal (*"No se construye… multi-CESFAM"*), and putting another
  clinic's figures in front of our staff is a governance decision nobody has taken.
- **A configured default plus one comparison clinic.** Same governance question, narrower. Deferred
  until someone can say who may compare against whom.

## Consequences

- Agnosticism costs nothing at the data layer: the DEIS extracts are national, `rem_fact.deis` and
  `rem_source.deis` already exist, and which clinic we show is a **filter value**, not a pipeline.
- The REM read API takes the DEIS code as a **parameter**, not an implicit "ours". That keeps a
  selector additive if the governance question is ever answered.
- Grepping for a hardcoded code is a real check, not a formality: before this decision,
  `grep 114302` across `analizador_rem` matched only prose in `docs/ESTADO.md`, and Epidemiología had
  no notion of an establishment at all. Both must keep returning nothing in code.
- Fixtures and tests must not assume a specific clinic either, or the agnosticism is untested.
