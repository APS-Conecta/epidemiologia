# AGENTS.md — Epidemiología (canonical repo rules)

Rules for any AI agent working in this repo. `CLAUDE.md` imports this file.

**This repo is nested inside another one.** It is cloned into `gestion/apps/epidemiologia`, which
`gestion` gitignores and bind-mounts to `/var/www/html/custom_apps`, so `gestion/AGENTS.md` loads as
parent context whenever you work here. Its rules still apply; nothing below replaces them.

Cross-repo ADR citations are `repo#ADR-NNNN` (`territorio#ADR-0016`); in-repo citations stay bare. The org-wide contracts index lives in `gestion/docs/CONTRACTS.md`.

**Language.** One line decides it: **Spanish is what a clinician reads. Everything else is English.**

| Surface | Language |
| --- | --- |
| UI strings — `t('epidemiologia', …)`, `n(…)`, anything rendered in the app | **Spanish** |
| Code, identifiers, comments, test names, docblocks | **English** |
| `README.md`, `CHANGELOG.md`, `CONTEXT.md`, `docs/` | **English** |
| `scripts/` output | **English** |
| `nextcloud.log` lines — every `LoggerInterface` message | **English** |

**Commit messages and issue comments are English, from 2026-08-08.** They were Spanish, and
everything up to that date stays Spanish — history is not rewritten. The carve-out went because it
contradicted the paragraph above it: `gestion/AGENTS.md` puts commits in English, and *"nothing below
replaces them"* is what makes nesting this repo inside that one work at all. Between a promise and an
exception to it, the promise is the load-bearing sentence. Issue *bodies* written as specs were
already English, as #1, #25 and #37 are.

## Working rules

- **Names:** code is English, but a domain term keeps the spelling `CONTEXT.md` gives it (`Fuente`, not
  `Source`). Rename an existing name only inside code a change already touches, and never a table, column,
  route, controller action (an OpenAPI operation id) or API field.
- **Threat model:** read `docs/threat-model.md` before any security work.
- **Gate before opening a PR** — what `ci.yml` and `docs.yml` run. This repo uses **npm**, not pnpm:
  `npm ci && npm test`; `npm run build`, then `git status --porcelain -- js/ css/` prints nothing;
  PHPUnit 11 in the instance image — `curl -sSLf -o tools/phpunit.phar https://phar.phpunit.de/phpunit-11.phar`, then
  `docker run --rm --entrypoint "" -e NEXTCLOUD_ROOT=/usr/src/nextcloud -v "$PWD":/app -w /app nextcloud:34-apache php tools/phpunit.phar`;
  `python3 .github/repo-docs.py check . --offline`. A step you could not run is named in the PR, never reported as passed.
- **`src/` changed → `npm run build`** and commit the regenerated `js/epidemiologia-main.mjs`, its `.license` and
  `css/` in the same PR. Never commit `*.map` or `node_modules/`.
- **Never edit** `.github/repo-docs.py`, `.github/profiles/*`, `package-lock.json`, `package.json` dependencies,
  `js/`/`css/` by hand, `openapi.json` (generated by `scripts/openapi.sh`), `src/aps/` (vendored from aps-common).
- **Strings:** UI text is Spanish via `t('epidemiologia', '…')` / `$l->t('…')`; code, comments, commits and PR text English.
- **One concern per PR**, under 50 lines of hand-written source (rebuilt bundle excluded), and it contains every change
  its description claims.
