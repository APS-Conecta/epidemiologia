# AGENTS.md — Epidemiología (canonical repo rules)

Rules for any AI agent working in this repo. `CLAUDE.md` imports this file.

**This repo is not nested.** It once cloned into `gestion/apps/epidemiologia`, a stack deleted at
the cutover (instalador #53): the suite now installs this app from its signed release, and a clone
is for development only. The suite's org-wide doctrine lives in the suite repository's `AGENTS.md`
and `docs/adr/` (`APS-Conecta/instalador`), which is the parent context to re-read for
organisation-wide rules.

Cross-repo ADR citations are `repo#ADR-NNNN` (`territorio#ADR-0016`); in-repo citations stay bare. The org-wide decisions live as ADRs in the suite repository (`APS-Conecta/instalador`, `docs/adr/`); cross-app contracts are each app's OpenAPI surface, indexed on the documentation site.

**Language.** One line decides it: **Spanish is what a clinician reads. Everything else is English.**

| Surface | Language |
| --- | --- |
| UI strings — `t('epidemiologia', …)`, `n(…)`, anything rendered in the app | **Spanish** |
| Code, identifiers, comments, test names, docblocks | **English** |
| `README.md` (and the community files the org defaults in `APS-Conecta/.github` serve) | **Spanish** — the org-wide contract |
| `CHANGELOG.md`, `CONTEXT.md`, `docs/` (ADRs, threat model) | **English** |
| `scripts/` output | **English** |
| `nextcloud.log` lines — every `LoggerInterface` message | **English** |

**Commit messages and issue comments are English, from 2026-08-08.** They were Spanish, and
everything up to that date stays Spanish — history is not rewritten. The carve-out went because it
contradicted the paragraph above it: `gestion/AGENTS.md` puts commits in English, and *"nothing below
replaces them"* is what makes nesting this repo inside that one work at all. Between a promise and an
exception to it, the promise is the load-bearing sentence. Issue *bodies* written as specs were
already English, as #1, #25 and #37 are.

## Working rules

- **Names:** code is English, but a domain term keeps the spelling `CONTEXT.md` gives it (`Fuente`, not
  `Source`). Rename an existing name only inside code a change already touches, and never a table, column,
  route, controller action (an OpenAPI operation id) or API field.
- **Threat model:** read `docs/threat-model.md` before any security work.
- **Gate before opening a PR** — what `ci.yml` and `release.yml` run. This repo uses **npm**, not pnpm:
  `npm ci && npm test`; `npm run build` still produces the `js/` and `css/` a clone needs to run —
  there is no committed bundle to keep current any more, and the release workflow builds and packs
  on every pull request; PHPUnit 11 in the instance image — `curl -sSLf -o tools/phpunit.phar https://phar.phpunit.de/phpunit-11.phar`, then
  `docker run --rm --entrypoint "" -e NEXTCLOUD_ROOT=/usr/src/nextcloud -v "$PWD":/app -w /app nextcloud:34-apache php tools/phpunit.phar`.
  A step you could not run is named in the PR, never reported as passed.
- **`src/` changed → `npm run build`** to run the app from a clone: `js/` and `css/` are build output,
  untracked, built and packed by the release workflow. Never commit `*.map` or `node_modules/`.
- **Never edit** `package-lock.json`, `package.json` dependencies,
  `openapi.json` (generated by `scripts/openapi.sh`), `src/aps/` (vendored from aps-common).
- **Strings:** UI text is Spanish via `t('epidemiologia', '…')` / `$l->t('…')`; code, comments, commits and PR text English.
- **One concern per PR**, under 50 lines of hand-written source (rebuilt bundle excluded), and it contains every change
  its description claims.
